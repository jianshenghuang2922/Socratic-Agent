## 修复：切换题型时静默无反应（真 bug）

`useQASession.changeQuestionType` 原本是 `if (!hasPending) requestNextQuestion(next)` —— 界面上有未作答的题时切题型，**什么都不发生**。用户视角是"点了简答题没反应"；UI 测试也卡在这（`.short-input` 永远不出现）。

改成：切题型时把未作答的旧题标记 `abandoned`，并**无条件出新题**。

- `types.ts`：`ChoiceQuestion` / `ShortQuestion` 加 `abandoned?: boolean`
- `ChoiceCard` / `ShortCard`：abandoned 时禁用交互 + 显示「此题已作废（题型已切换）」
- `globals.css`：`.card--abandoned`（虚线描边 + 降透明度）、`.card-abandoned`
- `MessageList.showNext`：abandoned 也算「本题已结束」，避免新题生成失败时「下一题」按钮消失
- `isPendingQuestion` / `pendingQuestionId` 排除 abandoned

## 修复：背景视频播放一段时间后画面偏移

`.bg__video` 上直接挂了 `transform: translateY(6%) scale(1.3)` + `will-change: transform`。带 transform 的 `<video>` 会被提升为独立合成层，逐帧更新时「视频固有尺寸 → 层尺寸」的缩放映射累积亚像素误差，解码器重建时层几何被重置，画面整体跳一下。

先排除了视频文件本身：`.tmp/mp4-info.mjs` 解析出**单轨道 1920×1080、单一 avc1 采样描述、10.55s** —— 没有多分辨率，不是文件问题。

修法：**新增 `.bg__frame` wrapper 承载 transform，`<video>` 回归纯布局尺寸**（`inset: 0` + `object-fit: cover` + `object-position`），并删掉 `will-change`。

- `BackgroundVideo.tsx`：video 外面包一层 `.bg__frame`
- `globals.css`：`--bg-zoom` / `--bg-lift` 与 transform 移到 `.bg__frame`（CSS 变量是继承的，父层要用就必须定义在父层）；移动端媒体查询同样改到 `.bg__frame`
- 效果精确等价：wrapper 尺寸 = 视口，`cover` 裁剪结果与原方案完全一致

验证（`.tmp/verify-bg.mjs`）：`videoTransform: none`、`willChange: auto`、`frameTransform: matrix(1.3,0,0,1.3,0,54)`、videoRect `x=-432,y=-81,1872x1170`（右边缘 1440 对齐、下移 54px=6%），**连续播放 100s 几何 maxΔ = 0px**。窄屏 zoom 1.16 同样生效。
